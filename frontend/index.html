ABOUT THE PROJECT

SentinelAI

Intelligent Network Threat Detection and Cybersecurity Assistant.

OBJECTIVE

What is SentinelAI?

SentinelAI is a machine-learning based network threat detection system designed to analyze network-flow data and identify potentially malicious activity.

MACHINE LEARNING

Detection Engine

SentinelAI uses a Random Forest classifier trained on CIC-IDS2017 network-flow data to classify network traffic into multiple attack categories.

TECHNOLOGY

Technology Stack

  • Python
  • Scikit-learn
  • FastAPI
  • HTML / CSS / JavaScript

DATASET

CIC-IDS2017

The project uses network-flow features from the CIC-IDS2017 intrusion detection dataset.
